## 💡 A minha forma de construir

```text
problema real → solução pequena → limites claros → testes → documentação → partilha
```

- 🔐 **Segurança primeiro:** scripts com comportamento previsível e limites explicados.
- 🧩 **Simplicidade útil:** ferramentas pequenas que resolvem um problema concreto.
- 📚 **Conhecimento reutilizável:** documentação concisa, sobretudo em português.
- 🤝 **Open source:** issues, melhorias de documentação e pull requests focados são bem-vindos.
