# João de Medeiros Terra

Systems analyst and developer building practical automation, Linux/sysadmin tools and applied Python experiments.

My public work currently focuses on making operational knowledge easier to reuse: safe Bash helpers, concise documentation in Portuguese, reproducible notebooks and document-processing experiments.

## What I'm building

- **[pt-sysadmin-toolkit](https://github.com/JMT0306/pt-sysadmin-toolkit)** — Bash scripts, cheatsheets and operational checklists for Linux, Docker, SSH, networking, backups and troubleshooting.
- **[ASTROAZOR](https://github.com/JMT0306/ASTROAZOR)** — educational astronomy notebooks with an Azores perspective; currently being structured into a reproducible learning path.
- **[AI_OCR_SOL](https://github.com/JMT0306/AI_OCR_SOL)** — Python experiments for extracting structured fields from invoices and scanned documents; currently being prepared for easier installation and reuse.
